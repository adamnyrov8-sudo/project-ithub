# Учебный Git-проект

Проект создан для практики работы с Git и GitHub:
коммитами, ветками, слиянием и разрешением конфликтов.

## Ветки проекта

- `master`
- `firstbranch`
- `second-branch`
- `third-branch`

## Описание конфликта

Конфликт возник в файле `notes.txt`, потому что ветки
`firstbranch` и `second-branch` изменили одну и ту же строку.

Я вручную объединил изменения, удалил маркеры конфликта Git
и создал отдельный коммит:

`Fix merge conflict in notes.txt`
